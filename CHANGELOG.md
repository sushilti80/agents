# Changelog

All notable changes to Daedalus Agent will be documented in this file.

## [1.0.0] - 2025-11-02

### Added
- Multi-mode architecture (Platform and Cloud Architect modes)
- Microsoft Entra ID (Azure AD) SSO authentication
- Persistent session management with Qdrant vector database
- Thread history sidebar for session browsing and restoration
- Vector-based conversation memory (RAG)
- Mode switching commands (/platform, /cloud)
- Session management commands (/sessions, /resume, /session)
- Custom UI branding (logo, theme, login page)
- MCP tool integration (Microsoft Docs, Sequential Thinking)
- Reusable agent_core framework
- Comprehensive documentation and guides

### Features
- 🔐 Enterprise SSO with OAuth 2.0
- 🎭 Dynamic mode switching
- 💾 Conversation persistence across sessions
- 🧠 Semantic search in conversation history
- 🎨 Customizable UI and branding
- 📚 Real-time Microsoft documentation access
- 🔧 Advanced reasoning with Sequential Thinking
